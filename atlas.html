Install ATLAS on Windows

  1. Click Download ATLAS for Windows above. The installer is hosted on the official Darkstar AIs GitHub release.
  2. Open your Downloads folder and locate ATLAS-Setup-Windows.exe.
  3. Scan the file with Microsoft Defender before running it.
  4. Run the installer and follow the setup instructions. ATLAS may need Ollama and an AI model installed separately for local conversations.

If Edge says the file “isn’t commonly downloaded,” that is a reputation warning for a new or unsigned download, not a malware scan result. Do not disable your security software. Only install software you trust.
